## Wire Transfers → Collected integration plan (Phase 2-3)
User requirement: when a wire transfer is marked Received, its amount should appear as "collected" at the GROUP level (Paid this month / Collected KPIs). NO auto-linking to invoices (manual matching only). Open Balance = invoices - receipts - received WTs? NO — user confirmed: collected display only; but earlier said yes to "Open = invoices - receipts - received WT". Decision: include received WTs in COLLECTED calculations only (safer, matches "να εμφανιζεται collected στο group"); do NOT change invoice outstanding() since WTs aren't allocated to invoices.

Places where collected is computed in server/routers/ar.ts (all from receipts in month range):
1. line ~447-451: groups list procedure (customersRouter.listGroups?) — collectedByCustomer Map from receipts monthStart-monthEnd; g.collected += ...; used for Customers page "Paid (this month)" summary.collected and per-group Collected column
2. line ~1010-1041: groupForecast procedure — collected from receipts start-end; used by GroupDetail "Paid (this month)" and CustomerDetail groupForecast display
3. line ~1123: groupAiSummary collectedThisMonth
4. line ~1732-1758: dashboard summary (Home.tsx data.collected) — uses db helper collectedThisMonth (find its name: 4th item in Promise.all -> likely db.sumReceiptsInRange or similar)
5. line ~1913-1916: smartEntries (Forecast page) — collectedByCustomer from receipts

Implementation: add helper in db.ts: listReceivedWireTransfersInRange(start,end) selecting wire_transfers where status=Received AND receivedDate>=start AND <end (fallback transferDate if receivedDate null). Then in each location add WT amounts into collectedByCustomer / collected sums. Note wire_transfers.amount is decimal string; receivedDate is bigint ms nullable.
Schema: wire_transfers cols: id, customerId, amount (decimal), currency, transferDate (bigint ms), status enum Pending/Received, referenceNumber, notes, receivedDate (bigint ms null), createdBy/updatedBy, createdAt/updatedAt.
Also add tests: server/wireTransferCollected.test.ts — create WT received this month for a customer, check groupForecast.collected includes it, dashboard collected includes it.
